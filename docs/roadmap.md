# Model Weave Roadmap

This roadmap describes current direction, not a promise of delivery, version assignment, or release date.

## Current

- v0.1.22 Primary View: model and derived Weave Map views share the upper viewer area while Details, Relationships, Diagnostics, Source Links, and Mermaid remain in the lower panel.
- v0.1.22 visual Color Legend: Applied Color Scheme shows grouped effective rows with fill, stroke, text, and configured or built-in source information.
- v0.1.22 Flow Diagram diagnostics accuracy: local Objects IDs are kept separate from external model references.
- v0.1.22 Declarative Settings support: Obsidian 1.13+ settings search with legacy Settings display compatibility.

## Next

- Color filter.
- Flow Diagram usability improvements.

## Later

- Communication View.
- State Machine View.
- Transition Matrix.
- View-driven Authoring.
- Source Links Explorer.
- Reference Explorer.
- Model Index View.

## Exploring

### Mobile Support

Model Weave is currently desktop-only because some desktop workflows depend on filesystem and Electron operations. A staged, view-focused Mobile MVP is being explored. Initial candidates are preview, diagram, diagnostics, vault navigation, and Zoom/Pan/Fit. Desktop-specific Source Links and file-opening operations may remain unavailable.

Mobile Support has no assigned version or release date and is tracked through the existing GitHub Issue.
