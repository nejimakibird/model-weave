# Model Weave v0.1.22

Model Weave v0.1.22 improves how derived relationship views, color information, settings, and Flow Diagram references are presented.

## Highlights

- Primary View lets a model and its derived Weave Map share the upper viewer area.
- Applied Color Scheme is now a visual Color Legend.
- Flow Diagram local IDs no longer appear as external references.
- Declarative Settings support improves discovery on Obsidian 1.13+.

## Primary View and Weave Map

- The upper viewer can offer `Model` and `Weave Map` as Primary Views when both are available.
- Weave Map remains a derived `ImpactSummary -> WeaveMapModel -> Mermaid source` view; it is not a Markdown format or a `type: weave_map` model.
- The lower Relationships panel continues to show relationship and impact details while Weave Map is open. Details, Diagnostics, and Source Links continue to describe the source model.
- The Mermaid tab follows the selected Primary View. For a non-Mermaid Model view with an available Weave Map, the tab stays in place and shows a localized empty state until Weave Map is selected.
- Weave Map has its own viewport and continues to support Focus, View Only, and PNG export paths.
- Flow Diagram keeps its Detail or Screen model sub-mode independently from the Model / Weave Map Primary View selection.

## Visual Color Legend

- Applied Color Scheme now presents a visual legend in Details.
- Effective rows are grouped by target and de-duplicated by `target + kind` while preserving the existing order.
- Each row previews fill, stroke, and text colors and identifies configured or built-in values.
- Model Primary View shows the current model view's effective target rows; Weave Map shows `target=weave_map` rows.
- A Model view without applicable colors shows a localized empty state.
- This release does not add a color filter.

## Flow Diagram reference diagnostics

- `Objects.id` is a local Flow Diagram node ID.
- `Flows.from` and `Flows.to` resolve against local `Objects.id` endpoints.
- `Objects.ref` remains an explicit external Model Weave reference.
- Plain `Flows.data` remains an edge label; Wikilink `Flows.data` remains an external relationship.
- The change prevents local IDs from entering external object-reference validation and Impact Analysis. Existing DFD reference behavior is unchanged.

## Declarative Settings

- Obsidian 1.13+ uses Declarative Settings definitions, including Settings search names and descriptions.
- Earlier Obsidian versions keep the existing `display()` Settings UI.
- Both paths use shared definitions and continue to apply normalization, saving, and open Preview refresh through `plugin.updateSettings()`.

## Compatibility and behavior notes

- This release makes no Model Weave FORMAT changes.
- `manifest.minAppVersion` remains `1.8.7`.
- Color filter, Communication View, State Machine View, and Mobile support are not part of v0.1.22.
