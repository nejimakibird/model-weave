# Model Weave v0.1.23

Model Weave v0.1.23 is a maintenance release focused on Obsidian Community review compatibility.

## Obsidian lint compatibility

- Updated `eslint-plugin-obsidianmd` from `0.3.0` to `0.4.1` and verified the plugin against the latest stable Obsidian lint ruleset.
- Resolved all `prefer-create-el` warnings by moving native DOM creation to Obsidian-compatible DOM helpers.

## DOM and Viewer compatibility

- Preserved document ownership across popout windows, `activeWindow` and `ownerDocument` boundaries, SVG generation, Mermaid rendering, and PNG export.

## External Source Links

- Local source root remains an explicitly configured, desktop-only feature for resolving Source Links to implementation files outside the Obsidian vault.
- Filesystem checks are limited to Source Link existence and file-type checks for those user-configured paths. Model Weave does not use this access as general-purpose storage outside the vault.

## Scope

- No FORMAT schema changes.
- No new model format or user-facing feature.
- This is a maintenance and compatibility release.
