# Model Weave v0.1.21

Model Weave v0.1.21 improves diagnostics and the model viewing workflow.

## Highlights

- Rule Conditions resolve qualified member references.
- Vault-wide Diagnostics adds an explicit static review workflow.
- Diagnostic messages and Markdown exports follow the selected UI language.
- Modeling Preview Focus mode makes one Preview easier to review without changing the workspace layout.

## Rule Condition member references

- Rule Conditions support `[[RULE-ID]].COND-ID` and `RULE-ID.COND-ID`.
- The canonical Conditions table remains:

  `id | expression | severity | message | notes`

- Compatible Conditions table forms continue to parse.
- Qualified references participate in completion and Impact Analysis.
- Empty and duplicate Condition IDs remain diagnostics.

## Vault-wide Diagnostics

- Run `Model Weave: Check all model diagnostics` explicitly from the Command Palette.
- The command rebuilds the full index, then performs static diagnostics across recognized Model Weave files.
- The modal shows Error, Warning, and Note summaries, diagnostics grouped by file, severity and diagnostic-code filters, Recheck, file/line navigation, and Markdown export.
- Mermaid rendering is not performed, so Mermaid render errors are outside this command's scope.

## Localized diagnostics

- Vault-wide Diagnostics Modal and Markdown export follow the UI language.
- Current File and Vault-wide Diagnostics use the same diagnostic message localization.
- Diagnostic code, file path, member reference, section/field identifiers, and expected header remain canonical.

## Focus mode

- Focus is an overlay-based Modeling Preview mode; it does not remove workspace leaves or enter OS/browser fullscreen.
- Toggle it from the Preview toolbar, `Model Weave: Toggle focus mode`, or Esc.
- Diagram-capable previews enable View when Focus starts and keep View enabled when Focus ends.
- Flow Diagram Detail/Screen state is preserved, as are zoom and pan where possible.
- When a Markdown editor is active, the command resolves the Preview for the same vault-relative file path. If a matching Preview cannot be identified safely, it shows a Notice.
- Only one Modeling Preview can be focused at a time.

## Compatibility and behavior notes

- This release makes no Model Weave FORMAT changes.
- Existing Rule Inputs behavior is preserved.
- Focus state is temporary; it does not update Markdown or Settings.
- Mobile support is not part of v0.1.21.
