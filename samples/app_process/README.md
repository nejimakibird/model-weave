# App Process Samples

Public Model Weave V0.7 samples for `app_process`.

- [PROC-INVENTORY-SEARCH.md](PROC-INVENTORY-SEARCH.md) - prose Steps compatibility sample.
- [PROC-SAMPLE-ORDER-ENTRY-FLOW.md](PROC-SAMPLE-ORDER-ENTRY-FLOW.md) - table-based Business Flow sample with lanes and explicit Flows.

Table-based Business Flow rendering uses `Steps` row order as the default flow and merges explicit `Flows` for branches, loops, alternate paths, and conditions.
